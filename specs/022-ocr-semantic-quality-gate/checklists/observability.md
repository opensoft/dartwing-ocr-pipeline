## Notes

- FR-018's "optional aggregate semantic-quality metrics" lacks enumeration of specific field names and types; this is a material completeness gap that should be resolved before implementation tasks are assigned.
- The distinction between "failed checks" and "row-level reasons" in FR-017 / US3 AS1 is underspecified; if they are different structures the spec should define both, and if they are the same the spec should say so explicitly.
- SC-007 ("reviewer can reproduce any semantic verdict from the two input files alone") is the strongest observability commitment in the spec and should be explicitly cross-referenced in FR-015 and FR-017 to ensure the evidence sufficiency requirements actually deliver that guarantee.
